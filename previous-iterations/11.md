# Iteration 11

The owner liked Dia's look (not its AI). It was built first as a choice,
the plain "lean" window by default and a "visual" style as a setting; the
benchmark showed the visual style costs nothing measurable, so the owner
dropped lean and the setting: the rounded card is the only look. Released
as 0.6.2.

## What changed

- **The card** (`src/tab.rs`): every page view (web view, new tab page,
  PDF viewer, screenshot area picker, HUD) lives in one `Fill` under the
  toolbar instead of the window's content view. `layout_card` sizes it to
  the page area, inset 6 pt (below the find bar when open); `web_frame()`
  is its bounds. Find bar open/close re-lays the card instead of resizing
  each page view.
- **The look**: card radius 10, clipped, separator border; no hairline
  under the toolbar (the loading line stays at its foot); capsule pill
  (`PILL_R` = 14); the window's background a dynamic tinted color
  (`tinted_background`, light and dark), which the transparent title bar
  shows too. `Fill` gained border and clip flags.
- **Fades** (`fade_in`): new tab page, find bar, launcher; 0.18 s Core
  Animation opacity, skipped under Reduce motion.
- Bench: `look`, `buttons` (every button shown and whether a click at its
  middle reaches it), `press <label>` (clicks through hit-testing). Tests
  `the_page_sits_in_a_rounded_card_that_follows_the_window` and
  `every_button_is_reachable_and_does_its_job` (toolbar, find bar and PDF
  buttons, asserting what each does: Fit page fits, Fit width doesn't,
  next/previous page, thumbnails, rotate, two-up, star on and off,
  back/forward/reload/home, Done). 172 tests; fmt and clippy clean.

## Traps

- **A Python edit script that opens a file for writing before reading it
  empties the file** (`open(p,'w').write(open(p).read())`): `src/tab.rs`
  was lost mid-session and rebuilt from git plus the session's edits.
  Read first, then write.
- **A search field's magnifying glass is an `NSButton` subview**, but the
  field takes the click: `buttons` skips views inside text fields.
- **A dynamic `NSColor` provider must return a pointer that outlives the
  call**: the light and dark colors are captured by the block, which lives
  in a thread-local.
- **The crash prompt arrives right after READY**: a harness that sends a
  command at launch must keep the lines before its reply.
- Escape in the find bar isn't a menu key (`key escape` says `none`); use
  `findesc`.
- A bench run from a backgrounded shell needs absolute paths (the cwd
  isn't kept).
- **Cargo's newer build layout** (`target/release/build/<pkg>/<hash>/out`,
  seen on CI's toolchain) broke `build.rs`'s "three folders up" guess, so
  the translate helper landed in `target/release/build/` and CI's
  translate test failed ("TRANSLATE err missing"); the 0.6.2 release run
  failed on it. `build.rs` now takes the folder holding `build`.
- **CI runners appear to have Reduce motion on**: no fades there. `LOOK`
  reports `motion=`, and the card test checks the outcome for either.
