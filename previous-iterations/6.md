# Iteration 6

The owner asked for a round of features that fit the mission, then added
four of their own mid-session (site data manager, swipe navigation,
address bar suggestions with a clear storage note, editable shortcuts).
One commit per feature; docs/FEATURES.md updated with each.

## What changed

- **Low Power Mode / thermal**: background tabs sleep after 1 minute while
  saving power (`sleep_after`, `saving_power`).
- **JavaScript off per site**: permission `javascript=deny`, site menu
  "Allow JavaScript", Settings → Site settings.
- **Settings → Tabs** (`src/usage.rs`): memory/CPU per tab's page process,
  the shell and WebKit's helpers; Sleep/Close per tab. **Heavy-tab badge**
  in the native tab (≥500 MB or ≥10% CPU in the background, 30 s tick).
- **Cookie banners hidden**: third shared content blocker, `css-display-none`
  on known consent-platform ids/classes (`privacy::BANNERS`), setting
  `hide_cookie_banners`, Shields-down sites exempt.
- **Save Page As** (⌘S) as `.webarchive`.
- **Search Tabs** (⇧⌘A, `src/tabsearch.rs`).
- **Pinned tabs** (first in window, never idle-sleep, kept by Close Other
  Tabs and session restore; `session.pinned`), **Mute Tab** (`_setPageMuted:`)
  and a speaker icon while playing (`_isPlayingAudio` KVO).
- **Per-site zoom** (`zoom` table).
- **Two-finger swipe** back/forward (`allowsBackForwardNavigationGestures`).
- **Address bar suggestions** (`src/suggest.rs`): past searches (`searches`
  table) and history, local only; Settings → Storage names the file
  (`browser.db`) and clears searches.
- **Site data manager** (`src/sitedata.rs`): site menu → Site Data… sheet,
  Settings → Site data.
- **Quick Look** for downloads (Quartz loaded on first use).
- **Editable shortcuts** (`src/shortcuts.rs`): Settings → Shortcuts records
  keys; overrides in the profile (`shortcut:<id>` settings rows), not
  `NSUserKeyEquivalents` (shared by all profiles, and tests would write it).
- **Web Store extension updates**: `extensions.webstore`, Update button,
  signature must prove the same id, new permissions re-asked, storage kept.
- **Passwords in frames**: script in every frame, frame's own site.
- **Opt-in Developer ID signing / notarization** in `bundle.sh` / `dmg.sh`
  (`SIGN_IDENTITY`, `NOTARY_PROFILE`). Not run: no account.
- Fixes: quitting while a sheet with a text field (prompt()) was up did
  nothing; bench mode no longer activates the app.

## Traps found

- **Quit was ignored while a sheet holding a text field was up** (a page's
  prompt(), Search Tabs). Quit now goes through `App::quit`, which ends
  sheets first. `applicationShouldTerminate:` isn't even called in that state.
- **Bench processes activated themselves** at launch (without `--on-top`);
  when one quit, macOS activated another test browser, which made
  `bench_window_is_on_screen` fail now and then. Fixed: bench never activates.
- `NSWindowTabGroup`: `addTabbedWindow:ordered:` on a window already in the
  group reorders `tabbedWindows` but **not the visible tab bar**. Use
  `removeWindow:` + `insertWindow:atIndex:`, and set the tab's accessory view
  again on the next turn (re-inserting drops it).
- The bench `menu` command didn't run menu delegates; it now calls
  `update_window_menu` for the Window menu.
- Tests must stay offline: Return on a search in the bar loads the real
  search engine. Use `savesearch` instead.
- Hidden bench windows can still get a late "became key" for another tab;
  select the tab explicitly (`switch i`) before acting on "the active tab".
