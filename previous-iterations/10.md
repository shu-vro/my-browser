# Iteration 10

The owner asked for Chrome's tab right-click menu (screenshot), without
vertical tabs. Not committed (the owner hasn't asked for commits).

## What changed

- **Tab menu** (`src/main.rs`: `watch_tab_menu`, `tab_menu_event`,
  `tab_menu`, `tab_command`, `TabCmd`). Right- or control-click on a tab
  shows, for the tab clicked (not the active one): New Tab to the Right,
  Move Tab to New Window, Move Tab to Split View, Reload, Duplicate,
  Pin/Unpin, Mute Tab, Mute Site, Add Tab to Reading List, Close, Close
  Duplicate Tabs, Close Other Tabs, Close Tabs to the Right, Reopen Closed
  Tab, Bookmark All Tabs. Items that can't apply are disabled.
- **How the click is caught**: AppKit's tab bar has no public menu hook. A
  local event monitor on mouse-down hit-tests the window's frame view and
  walks up to the `NSTabButton`, whose private `associatedWindow` gives the
  tab's window (`TUNE tab_menu`; without it AppKit's own menu shows). Found
  with a small Swift probe dumping the title bar's view tree and the class's
  methods.
- **Mute Site** is a new `sound` site permission (`deny` = muted), in
  Settings → Site settings as "Sound". `Tab::apply_mute` mutes for the tab
  or its site, and runs on every commit, so later tabs and navigations on
  the site are muted too. Disabled in private tabs (it would store the
  site).
- Close Other Tabs (⌥⌘W) now goes through `tab_command` too; Reopen Closed
  Tab moved into `App::reopen_closed_tab`.
- Bench: `tabmenu <i>[ <title>]`, `tabclick <i>` (a synthetic right-click
  on the tab's button; prints the menu instead of popping it up). Test
  `tab_bar_menu_acts_on_the_clicked_tab`. 170 tests, all passing; fmt and
  clippy clean.

## Decisions, versus the screenshot

- **Skipped**: Use vertical tabs (owner), Add Tab to New Group (AppKit's tab
  bar can't colour or group tabs).
- **Pin is in**: the owner thought it didn't exist; Window → Pin Tab has
  been there since 0.3, so the item costs one line.
- **Split view is two windows side by side**, each half the screen's
  visible frame: an AppKit tab holds one page. The tab clicked goes right,
  the one shown (or last used) left.
- **Reading list and Bookmark All Tabs are bookmark folders** ("Reading
  List", "Tabs, <date>"), no new storage. Bookmark All has no name prompt:
  closing a sheet activates the app (iteration 9 trap).
- **Restore window is Reopen Closed Tab**: closed tabs are kept as URLs
  only, not as windows.
- Not benchmarked: nothing runs while idle (the monitor only sees
  mouse-downs).

## Traps

- **The tab bar lives in the shown tab's window only.** Other tabs'
  windows are ordered out and have no tab buttons; look in
  `tabGroup.selectedWindow`.
- **Hidden bench windows have no tab bar**: `tabclick` needs `--on-top`.
