# Iteration 7

The owner reported fojik.com hijacking clicks: a click anywhere opened the
site in a new tab and sent the current tab to an ad. Brave stops it.

## What changed

- **Ad blocking**: `scripts/update-trackers.py` now also folds EasyList's
  `easylist_adservers.txt` and `easylist_adservers_popup.txt` into
  `resources/trackers.bin`. Plain domain rules only: `||d^` and
  `$third-party` become third-party blocks, `$popup` becomes WebKit's
  `popup` resource type, `$document` blocks everywhere. Domains Disconnect
  already lists (or their subdomains) are skipped so its owner exemptions
  hold. Same list as the trackers, so Shields down exempts ads too.
- Unit test asserts the `llvpn.com` and a `popup` rule are in the list.

## Cause on fojik.com

An inline script injects `https://llvpn.com/tag.min.js` with
`data-zone=9340041` (Monetag pop-under). On click it does a tab-under:
opens the page in a new tab and navigates the current one to
`luugy.com/partitial/...`. Brave blocks it with EasyList's `||llvpn.com^`.
Reproduced with the bench protocol (`go`, `eval` a click, `tabs`): base
build 2 tabs and the ad URL; new build 1 tab, script never loaded.

## Measured (2026-10-17)

- Rules 4,042 → 53,196; packed 261 → 720 KB; JSON 6.5 → 12.9 MB.
- WebKit compile (temp store, swift harness): 0.70 → 1.39 s. Compiled list
  on disk 12 → 31 MB.
- Warm A/B, `bench --only startup,pages --page text`, base → new: idle
  footprint 78.3 → 78.8 MB, shell 32.7 → 33.3 MB, startup 150 → 150 ms,
  text 170.4 → 170.8 MB, text peak 318.4 → 318.1 MB. Noise.

## Traps

- **A/B runs share WebKit's compiled-list cache.** Each build deletes the
  other's `trackers-*` list (`forget_old_lists`), so alternating base/new
  recompiles every run: startup +700 ms and shell +11–19 MB in those runs.
  Run each build twice and use the second.
- A cold compile leaves the shell ~20–30 MB heavier for the session (the
  inflated JSON and its NSString copy). Pre-existing, now larger; also hits
  after each Shields change.

## Open items

1. Shell footprint after a compile (above): compile in a way that frees
   the JSON pages, or measure whether it matters.
2. Cosmetic filters and scriptlets (Brave's other layers) are not done:
   they need a script per frame. Revisit only for a site the network rules
   miss.
3. EasyList ad-server domains rotate; rerun `update-trackers.py` per release.
