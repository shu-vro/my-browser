# Iteration 8

The owner asked for a batch of features other browsers have (from a gap
review in `experiments/new-features..md`), then, mid-session: developer
tools with a setting, local addresses over HTTP, find with a match count
and highlights, an Edge-like PDF viewer, images and media in the tab, a
file-manager view for pasted paths, and gestures and zoom like other
browsers'. Not committed (the owner hasn't asked for commits).

## What changed

- **Hide Element and My filters** (`privacy::filter_rules`, a fourth shared
  content-rule list from the `filters` settings row; `resources/picker.js`).
  uBlock syntax subset: `##sel`, `a.com##sel`, `~a.com##sel`,
  `||host^[$third-party]`. A list WebKit refuses isn't saved.
- **Translate Page** (⌥⌘T): `resources/translate.js` collects text nodes;
  `helpers/translate.swift` (built by the new `build.rs` next to the binary,
  copied and signed by `bundle.sh`) translates on-device with Apple's
  Translation framework, in its own process, closed after a minute idle.
- **Profiles** (`src/profiles.rs`): `profiles/<name>` folders, each opened as
  its own copy of the app; Dock badge and address-bar placeholder.
- **Autofill** (`src/autofill.rs`, `passwords.js`): addresses in SQLite,
  card numbers in the keychain (generic passwords by a random ref), filled
  from a native menu; cards only on HTTPS/local, after Touch ID.
- **Auto picture in picture** when leaving a tab whose video plays with
  sound; back in the page on return. Tabs playing sound no longer fall
  asleep on the idle timer.
- **Full-page screenshot** (⇧⌘S): `createPDF` → bitmap at 2× → PNG.
- **Search keywords and bangs** (`keyword_url`, `BANGS`, `keywords` table).
- **Spelling**: WebKit's continuous spell check was off; it's on by default
  now (registered default), with Edit → Spelling and Grammar.
- **Extension `commands`**: an Extensions menu of commands with their
  suggested keys (changeable in Settings → Shortcuts).
- **Sync by file** (`src/syncfile.rs`): export/import JSON; no passwords or
  cards in it.
- **Developer tools** (owner's decision; DESIGN-DECISIONS has the entry):
  `isInspectable` + private developer extras, View → Show Web Inspector
  (⌥⌘I), `devtools` setting.
- **Local addresses**: `localhost:3000` → `http://`, no HTTPS-first upgrade
  for local hosts (`privacy::is_local_host`, `keep_scheme`), computer icon.
- **Find**: "3 of 17", all matches and the current one highlighted
  (`resources/find.js`, CSS Custom Highlight API).
- **PDF viewer** (`src/pdf.rs`, PDFKit over WebKit's PDF page).
- **Paths and folders** (`src/files.rs`): typed paths open; folders are
  `mybrowser://files/…` pages; unshowable local files open in their app
  (code only revealed in Finder).
- **Gestures and zoom**: pinch/smart zoom, swipe and ⌘-scroll settings,
  Chrome's zoom steps, a default zoom, a zoom button by the star.
- Settings: General (translate, PiP, devtools, gestures, keywords), Privacy
  (My filters), new Autofill, Profiles, Sync sections.

### Second round (owner's feedback, same day)

## Measured (2026-10-20)

Startup A/B against the previous commit (worktree build), `bench --only
startup --runs 1`, second run of each (the first pays one-time rule-list
compiles): idle footprint 73.85 → 73.64 MB, shell 30.78 → 30.91 MB,
startup 140 → 134 ms, idle wakeups 7.0 → 6.8/s, CPU 0.69 → 0.71 ms/s.
Parity. Page benchmarks weren't run (passwords.js grew; same listeners).

Tests: 161 (8 bench, 69 unit, 84 e2e), all passing; one run had a
one-off timeout in `video_fullscreen_picture_in_picture_and_screen_sharing`
under load that didn't come back in four reruns.

## Traps

- **`LOADED` comes only for bench-started loads.** Clicks made with `eval`
  need `state_until`.
- **A cancelled local load** (opened in its app) ends with "Frame load
  interrupted" a moment later, which the next bench navigation can catch.
- **WebKit tolerates invalid `css-display-none` selectors** one by one; a
  bad user selector doesn't break the list.
- **`CSS.highlights` is a per-world maplike**: the page world's `size` can
  lag the browser world's changes; `keys()` is right.
- **WebKit refuses links from a `mybrowser:` page to `file:`**: folder
  pages link to `mybrowser://open/…` and the browser opens the file.
- **File names in HTML attributes need `escape_html`**, not `json_str`
  (caught by a unit test: a name with `"` could add attributes).
- **`isContinuousSpellCheckingEnabled` isn't on WKWebView**; read the state
  through `validateUserInterfaceItem:` on a menu item.
- **AppKit stopped clipping subviews by default in macOS 14**: views that
  draw past their frame (PDFView) show through siblings. `setClipsToBounds`.
- **NSSpeechSynthesizer word ranges are UTF-16 offsets** into the spoken
  string; keep a map back to each page's text (`Viewer::spoken`).
- **Opening Settings in bench mode makes the app active and key** (`key
  cmd+,` → `WINDOW key=1 app_active=1`). Pre-existing (same on the previous
  commit), against the "never take focus" rule.

## Open items, in priority order

1. Settings opening takes focus in bench mode (above).
2. Saved passwords and cards are shared by all profiles (keychain items
   carry no profile). Tag new items with the profile id and filter on it.
3. Autofill never offers to save an address or card from a submitted form.
4. PDFs are in memory twice while shown; measure a large PDF.
5. Translate Page is tested with the fake helper only; real translation
   was checked by hand (fr→en, de→en) on macOS 27.
6. ⌘-scroll and pinch haven't been tried with a real trackpad or mouse
   yet: tests cover their settings and WebKit's state, not the gestures.
7. Filter lists by subscription (EasyList Cookie, Fanboy) need the network
   gate; only typed rules today. Hide Element works in the main frame only.
8. Folder pages: icons only, no image thumbnails; not restored with the
   session. MKV/AVI open in their app (WebKit can't play them).
9. The sync file has no extensions (Web Store ids could be listed).
10. The right-click Translate Page / Take Screenshot items have no test (the
    context menu needs a real right-click); the area picker is tested with
    synthetic drags. A translate button in the address bar for
    foreign-language pages would make Translate easier to find.
11. White areas a page leaves unpainted after it loads (e.g. a dark site
    that doesn't color its root) still show WebKit's white canvas; only the
    loading flash follows the theme.
12. Earlier open items (iterations 6 and 7).
