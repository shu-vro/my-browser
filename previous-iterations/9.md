# Iteration 9

The owner liked the look of Zephium (a Rust + Tauri browser whose UI is a
Svelte page in a web view) and asked for a UI that looks as good, with the
lowest possible memory spikes, keeping memory and security in mind: "what
they do, not how they do it". The work was split across five agents in
separate worktrees and merged by hand. Not committed (the owner hasn't
asked for commits).

## Why not their approach

A web-drawn UI needs a page process per window. We measured that cost
before: an HTML new tab page took the browser from 28.8 to 72.5 MB. Their
own docs report ~96 MB for the main process alone and ~118 MB for the whole
process family. Everything here is native AppKit or HTML only on internal
pages that run while open.

## What changed

- **Toolbar and window** (`src/tab.rs`): transparent title bar so title,
  native tab bar and toolbar read as one surface; 40 pt row; flat toolbar
  bezel buttons (AppKit draws hover and press); SF Symbols with a size and
  weight; a rounded address pill (`AddressField`, `Fill`: layer colour and
  corner only, no backing store) with the site button, zoom and star inside;
  a dark pill in private windows; hairlines; a 2 pt loading line from
  `estimatedProgress` KVO (removed in `destroy_web` like the other keys;
  moves the line only, not `refresh_toolbar`). Suggestions open under the
  pill. Bench `progress`.
- **New tab page** (`src/home.rs`): gradient glow background, gradient
  banner, search pill, letter tiles for top sites (colour hashed from the
  site name; no favicons, so no network), a status line (tabs, asleep tabs,
  the browser's memory, shields) behind the new `home_stats` setting.
- **Launcher** (`src/tabsearch.rs`, ⇧⌘A, "Search Tabs and More…"): tabs,
  menu-bar commands with their current shortcuts, bookmarks and history in
  one list. Commands run through `performActionForItemAtIndex:` (no new
  action path). Private windows see only private tabs and no history. A
  child panel, not a sheet: closing a sheet activates the app, which breaks
  the bench focus rule. Built on open, freed on close. Bench `launcher`.
- **Internal pages**: settings restyled like System Settings (icons per
  section, cards from CSS selectors alone, switches that are still
  checkboxes); folder, error and reader pages share `PAGE_CSS`. No ids,
  bridge ops, CSP or escaping changed. Binary +16 KB.
- **Tab memory** (`src/main.rs` `to_sleep`, `warm_tabs`, `Tab::keep_awake`):
  - at most `awake_tabs_max` (default 4, 2 when saving power) background
    tabs stay awake; the rest sleep on the existing 30 s tick;
  - a background tab whose page process is 256 MB or more sleeps after 3
    minutes, except the most recently used one;
  - links opened in background tabs (⌘-click, Open Link in New Tab) open
    asleep once the cap is full; popups and extension tabs always load;
  - pinned, sound, camera/microphone, open sheet and visible-in-another-window
    tabs are exempt (the camera, sheet and visible exemptions also apply to
    the idle timer now). Bench `tick`.

### Second round (owner's feedback, same day)

- **Downloads** (`src/downloads.rs`): a downloads button right of the
  address pill (as in Safari) with a 3 pt bar while one runs, and a popover
  list of this session's downloads (open, show in Finder, cancel, Show All,
  Clear). Files are written to `<name>.download` and renamed when done;
  cancelled and failed ones delete it. Cancel was broken: WebKit doesn't
  call `download:didFailWithError:` after `cancel:`, so the row stayed
  "active" and the half file stayed; it now ends in `cancel:`'s completion
  handler. Crash leftovers' `.download` files go at launch. A half-second
  progress timer runs only while a download does.
- **Site settings** grouped by permission (one card per kind, only sites
  with an answer, × forgets it, a filter), instead of every control for
  every site.
- **↑/↓ in an untouched address bar** (empty or the page's address) or the
  new tab page's search lists the 8 latest searches, text only
  (`Store::recent_searches`); with text typed, its matches. The new tab
  search field now suggests while typing too.

## Traps

- **Closing any sheet activates the app**, even with `--on-top`; page
  alert sheets and the print panel still do it. Use child panels for
  anything bench drives.
- **Focus rings and hover borders only draw in the key window**, and bench
  windows never become key: screenshots can't show them.
- **A view that draws gets a layer bitmap** (~35 KB plus its area); layer
  colours, gradients and corners are free. Prefer layer properties to
  `drawRect`.
- **Synthetic ⌘-clicks from JavaScript don't open tabs** (WebKit ignores
  the modifier on script events); test through `linkmenu`.
- **Parallel agents share the scratchpad**: use distinct file names.
- **`WKDownload.cancel:` doesn't call the delegate**: end the download in
  its completion handler.
- **A WKDownload's address is reused** by the next download: never key
  anything that outlives it by its pointer (the list's first version
  marked an old row done for a new download).
